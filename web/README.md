# Hashly web

Landing y app (Next.js). Se levanta junto al API; ver el [README principal](../README.md).

```bash
npm install
npm run dev        # http://localhost:3000
```

`NEXT_PUBLIC_API_URL` apunta al API (por defecto `http://localhost:8000`).

Rutas: `/` (landing), `/entrar`, `/panel` (sellar, mis paquetes, API keys), `/verificar` (público).
